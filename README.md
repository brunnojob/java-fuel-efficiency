# java-fuel-efficiency

Java 17 CLI for vehicle fill-up history. Stores validated odometer and fuel records in CSV and reports liters per 100 km between fills.

Compile with `javac FuelLog.java`. Add: `java FuelLog fuel.csv add 2026-10-03 12000 38.5`. Report: `java FuelLog fuel.csv report`.
